XGBoost 预备课

正文里的公式只用到几样数学工具：下标、求和、函数、导数、抛物线的最低点和 sigmoid。这一篇一样一样讲，每样都配一张能动的小图、一句“念法”和几行等价的 Python 代码。读完再回去看正文，每个公式你都能念出来，也能自己算出来。

一个公式就是一行计算：给每个字母填上数，按顺序算出来。后面十章按“念得出、算得出”的顺序排：先认符号（第 1–3 章），再看误差怎么量（第 4–5 章），再学找最低点的工具（第 6–8 章），最后回到 Ω 本身（第 9 章）和正文的全部公式（第 10 章）。

第 1 章

下标、上标、帽子和星号

公式里的大部分符号只是在给数据起名字。先把名字认全。

  • 下标是编号。17 个西瓜从 1 编到 17。第 i 个瓜的特征记作 xi（密度、含糖率），真实答案记作 yi（好瓜 = 1，坏瓜 = 0）。右下角的小字就是代码里的方括号：x[i]、y[i]。
  • 帽子表示预测。ŷ 读作“y hat”，是模型猜的值；y 是真实答案。两个要分清。
  • 带括号的上标表示轮次。XGBoost 一轮加一棵树，第 t 轮之后的预测写成 ŷi(t)。括号里的 t 不是乘方。
  • 不带括号的上标才是乘方。w2 = w × w。
  • 星号表示“最好的那个”。w* 是能让目标最小的 w。
  • 字母挨着写就是相乘。γT 就是 γ × T。

第 2 章

Σ：会循环的求和符号

Σ 是希腊字母 sigma 的大写，在公式里只有一个意思：把一串数加起来。它就是一个 for 循环。

TΣj=1 wj2 = w12 + w22 + … + wT2

三个位置各管一件事：Σ 下面写从哪开始（j = 1），上面写到哪结束（T），右边写每一项长什么样（wj2）。j 就是循环变量。

还有一种写法把条件写在下面，比如 Σi∈Ij gi：只加那些编号属于集合 Ij 的样本。这就是循环里多了一个 if。

正文里的 Σ 都是这两种之一：Σi 对所有样本加，Σj 对所有叶子加，Σk 对所有树加，Σi∈Ij 只对第 j 片叶子里的样本加。

第 3 章

函数和决策树：f(x) = wq(x)

函数是一台机器：放进一个输入，吐出一个输出。f(x) = 2x + 1 是一台机器，一棵决策树也是。

XGBoost 的树这样工作：输入一个瓜的特征 x，从根开始回答一串“是 / 否”问题，停在某片叶子上，输出那片叶子上的分数。正文把它拆成两步写：

第一步 · 找叶子q(x) = 这个瓜落进第几片叶子（叶子编号 1、2、3）
第二步 · 取分数wq(x) = 分数表 w 里的第 q(x) 个，代码里写 w[q(x)]

叶子上放的是一个数，可正可负，不是“好瓜 / 坏瓜”。正数往好瓜推，负数往坏瓜推，最后再换算成概率（第 5 章）。

XGBoost 的模型是很多棵这样的树加起来：ŷ = f1(x) + f2(x) + … + fK(x) = Σk=1K fk(x)。下标 k 是树的编号，K 是树的总数。

第 4 章

损失函数：量一量错了多少

训练需要一个“错了多少”的分数，叫损失函数，写作 l(y, ŷ)：给它真实答案 y 和预测 ŷ，它返回一个不小于 0 的数，越小越好。

回归用平方损失 l = ½(y − ŷ)²。差多少，就罚差值的平方。平方有两个好处：结果总是正的；离得越远罚得越狠，差 2 罚 4，差 4 罚 16。前面的 ½ 只是为了求导时约掉 2，不改变哪个预测更好。

分类用对数损失。模型给出“是好瓜”的概率 p。如果它真是好瓜（y = 1），损失是 −ln p；如果是坏瓜（y = 0），损失是 −ln(1 − p)。ln 是自然对数，你只要知道：ln 1 = 0，p 越小 −ln p 越大，p 接近 0 时会冲得很大。说得越有把握、结果又错了，罚得越重。

整个数据集的损失，就是把每个样本的损失加起来：Σi l(yi, ŷi)。正文目标函数 Obj 的第一项就是它。训练开始时每个瓜的 p 都是 0.5，每个的损失都是 −ln 0.5 = 0.693，17 个瓜合计 11.78。

第 5 章

分数怎么变成概率：sigmoid 和 log-odds

对数损失需要一个 0 到 1 之间的概率 p，可树输出的分数可正可负，加起来可能是 3.7，也可能是 −12。换算的工具是 sigmoid 函数：

p = σ(z) = 11 + e−ze ≈ 2.718，是一个常数

不用记它怎么算，记住三点就够：z = 0 时 p = 0.5；z 越大 p 越接近 1，z 越小 p 越接近 0；不管 z 多大多小，p 都不会越过 0 和 1。

反过来，从 p 算回 z 是 z = ln(p/(1 − p))，叫 log-odds（对数几率）。p/(1 − p) 是赔率：p = 0.8 时赔率是 4，意思是“是好瓜”的可能性是“是坏瓜”的 4 倍。

所以 XGBoost 做分类时，所有树的分数都加在 z 上，最后才用 σ 换成概率。在 z 上怎么加减都不会越界，所以加法放在这里做。正文里的 ŷ 在分类任务中就是这个 z。

第 6 章

导数：曲线在这一点有多陡

导数回答一个问题：输入挪一点点，输出变多少？

把一个好瓜（y = 1）的损失看成预测 ŷ 的函数，画成一条曲线。在某个 ŷ 处往右挪一小步 Δŷ，损失变化 Δl，比值 Δl/Δŷ 就是这一小段的平均坡度。步子越小，这个比值越稳定，最后稳定下来的那个数就是导数，也就是这一点切线的斜率。

正文把它写作 g = ∂l/∂ŷ，念作“l 对 ŷ 的偏导”。“偏”的意思是只让 ŷ 变，其他量（比如 y）不动。可以把 ∂ 读成“一点点变化”。

导数的正负告诉你方向：g < 0 说明把 ŷ 调大损失会下降，g > 0 就该调小。沿着 −g 的方向走，叫梯度下降。

导数本身也随 ŷ 变化。把每个位置的导数画成一条新曲线，再求一次导，就是二阶导 h = ∂²l/∂ŷ²（右上角的 2 表示“求两次”）。它描述原曲线弯得多厉害：h 大，曲线弯得急；h 接近 0，曲线几乎是直的。对数损失的两个导数正好很简单：g = p − y，h = p(1 − p)。图里用“挪一小步”算出来的数和它们一致。

第 7 章

抛物线的最低点：整篇正文最关键的一步

这一步初中就学过：当 a > 0 时，抛物线 a·w² + b·w 开口朝上，在 w = −b/(2a) 处最低，最低值是 −b²/(4a)。

为什么？最低点处曲线是平的，切线斜率为 0。这条抛物线的导数是 2a·w + b（第 6 章），令它等于 0，就解出 w = −b/(2a)。

XGBoost 每片叶子要最小化的，正好是一条这样的抛物线：G·w + ½(H + λ)·w²，其中 G、H 是这片叶子里所有样本的 g、h 之和。对照一下，a = ½(H + λ)，b = G，代进去：

w* = − G2 · ½(H + λ) = − GH + λ最低值 = − G24 · ½(H + λ) = − 12 · G2H + λ

这两行就是正文第 4 章的叶子权重公式和结构分数。看懂了这一章，正文里最长的 Gain 公式也只是“切开后两片叶子的最低值”和“不切时的最低值”相减。

第 8 章

泰勒展开：用抛物线冒充一条曲线

对数损失的曲线不是抛物线，没法直接套第 7 章的公式。XGBoost 的办法是：在当前这一点附近，找一条抛物线冒充它。怎么找？一层一层加信息。

  • 0 阶：只知道当前的值 l0。用一条水平线去猜，离开一点就不准。
  • 1 阶：再加上斜率 g，得到切线 l0 + g·f（f 是往前挪的距离）。近处准，远了偏。
  • 2 阶：再加上弯曲程度 h，得到抛物线 l0 + g·f + ½h·f²。它在这一点的值、斜率、弯曲都和真曲线一样，能贴得更久。

这就是二阶泰勒展开。½ 是展开式第二项固定的系数，和第 7 章抛物线里的 ½ 是同一个 ½。

为什么非要换成抛物线？因为抛物线的最低点我们会算。XGBoost 把每个样本的损失都换成抛物线，一片叶子里的抛物线加起来还是抛物线，于是这片叶子该填多少分，一个公式就算出来了。

第 9 章

正则化：给复杂度打分

如果只追求训练误差最小，最“好”的树是把每个训练样本都单独分进一片叶子、分数还定得很极端的树。它把训练集背了下来，换一批瓜就不灵了，这叫过拟合。

XGBoost 在目标函数里加了一项复杂度罚分：

Obj =  Σi l(yi, ŷi) + Ω(f)Ω(f) = γT + 12λ TΣj=1 wj2

现在它应该能念出来了。Ω 分两部分：γT 是每片叶子收 γ 的罚金，叶子越多罚得越多；½λΣwj² 是把每片叶子分数的平方加起来再乘 ½λ，分数越极端罚得越多。用平方是因为它总是正的，而且分数翻倍、罚分变成 4 倍。
