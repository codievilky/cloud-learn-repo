第 1 章

加法模型：一棵树不够，就再加一棵

先看一个回归任务：用一天里的时刻预测城市的用电负荷。一棵深度为 2 的树最多只有 4 片叶子，只能把 24 小时切成 4 段、每段给一个常数，单独用它肯定拟合不好。

Boosting 的做法是把很多这样的树串起来：

ŷ(0) = base_scoreŷ(t) = ŷ(t−1) + η · ft(x)

第 t 棵树 ft 不去拟合原始的 y，而是拟合前面 t−1 棵树留下的残差 y − ŷ(t−1)。η 是学习率（参数 eta），它让每棵树只走一小步，剩下的误差留给后面的树继续修。

留意两件事。每棵树的输出（下半部分的阶梯线）越来越矮，因为残差在变小。η 越小，需要的树越多，曲线也更平滑，不容易过拟合。

对平方损失 l = ½(y − ŷ)²，残差正好是负梯度：g = ∂l/∂ŷ = ŷ − y。所以“拟合残差”其实就是“沿负梯度走一步”。换成别的损失函数（比如分类用的对数损失），“残差”这个说法就不够用了。XGBoost 用的是更一般的一阶导 g 和二阶导 h，这是第 3 章的内容。

第 2 章

目标函数：既要准，又要简单

XGBoost 训练时最小化的目标函数由两部分组成：

Obj =  Σi l(yi, ŷi) +  Σk Ω(fk)预测误差 + 所有树的复杂度

一棵树可以写成 f(x) = wq(x)：q(x) 负责把样本送到某片叶子，w 是每片叶子上的分数。一棵树的复杂度定义成：

Ω(f) = γT + 12λ TΣj=1 wj2

T 是叶子数，每多一片叶子要多付 γ。wj 是叶子分数，分数越极端罚得越多，力度由 λ 决定。这两个参数后面会反复出现：λ 在叶子权重和分裂增益的分母里，γ 是一次分裂必须越过的门槛。

没有这一项会怎样？树会一直长到每片叶子只剩一个样本，叶子分数也会变得很极端，训练误差趋近 0，但在新数据上表现很差。正则项让“多分一次”和“分数更大”都有代价，只有带来的误差下降足够多时才值得。

第 3 章

二阶泰勒展开：g 和 h 从哪来

第 t 轮时，前 t−1 棵树已经固定，要找的只有新树 ft：

Obj(t) =  Σi l(yi, ŷi(t−1) + ft(xi)) + Ω(ft)

损失函数 l 可能很复杂，直接对“一棵树”求最优解很难。XGBoost 在当前预测附近，把每个样本的损失近似成一条抛物线：

l(y, ŷ + f) ≈ l(y, ŷ) + g·f + 12h·f2g = ∂l∂ŷ,h = ∂2l∂ŷ2

g 是斜率，说明往哪边改预测能让损失下降；h 是弯曲程度，说明这条抛物线有多陡。只看一个样本的话，抛物线的最低点在 f = −g/h，这就是牛顿法的一步。加上正则 λ 以后变成 f = −g/(h+λ)，步子更小、更保守。

二分类常用对数损失。模型输出的 ŷ 是 log-odds，概率 p = σ(ŷ) = 1/(1+e−ŷ)，求导得到：

对数损失：g = p − y,h = p(1 − p)平方损失：g = ŷ − y,h = 1

从这里开始，建树算法不再需要知道损失函数长什么样。每个样本只要交出 gi 和 hi 两个数，后面的步骤对所有损失函数都一样。这也是 XGBoost 能支持自定义目标函数的原因：自定义目标只需要返回 grad 和 hess。

和传统 GBDT 比：GBDT 用负梯度（一阶信息）决定树怎么分裂；XGBoost 在分裂和叶子取值时同时用了 g 和 h，并且把正则项直接写进了公式。

h = p(1−p) 在 p = 0.5 时最大（0.25），模型越确定（p 接近 0 或 1）它越小。可以把 h 理解成样本的权重：已经学得很有把握的样本，在后面的树里分量更轻。

第 4 章

叶子上该填什么数：w*

先假设树的结构已经定了。落在同一片叶子 j 里的样本（集合 Ij）得到同一个输出 wj。把泰勒展开代进目标函数，去掉和 ft 无关的常数，再按叶子归并：

Obj(t) ≈ TΣj=1 [ Gjwj + 12(Hj + λ)wj2 ] + γTGj =  Σi∈Ijgi,Hj =  Σi∈Ijhi

每片叶子各自是一条关于 wj 的抛物线，互不影响，可以分别求最低点：

wj* = − GjHj + λObj* = − 12 TΣj=1 Gj2Hj + λ + γT

Obj* 叫结构分数（structure score），越小说明这种分法越好。它只依赖每片叶子里 g、h 的总和。下面用西瓜数据的第一轮来演示：所有瓜的初始预测都是 p = 0.5（log-odds 为 0），所以好瓜 g = 0.5 − 1 = −0.5，坏瓜 g = +0.5，h 都是 0.25。

第 5 章

在哪里切一刀：Gain 与贪心扫描

有了结构分数，就能比较“切”和“不切”。把一个节点分成左右两个孩子，目标函数的下降量是：

Gain = 12 [ GL2HL + λ + GR2HR + λ − (GL + GR)2HL + HR + λ ] − γ

前两项是切开以后左右两片叶子的分数，第三项是不切时的分数，γ 是多出一片叶子的代价。Gain 越大越好；如果最好的 Gain 都不大于 0，这个节点就不切了。

怎么找到 Gain 最大的切法？精确贪心算法（exact greedy）：对每个特征，把节点里的样本按特征值排好序，从左往右扫一遍。每往右挪一格，只要把一个样本的 g、h 从右边挪到左边，GL、HL 累加即可，右边用 G − GL 算。扫完所有特征，取 Gain 最大的位置。

图里画 × 的位置不允许切：某一侧的 H 之和小于 min_child_weight。第一轮每个瓜的 h 都是 0.25，所以 min_child_weight = 0.5 意味着每侧至少 2 个瓜；XGBoost 的默认值是 1，也就是至少 4 个瓜。min_child_weight 限制的是 h 的总和，不是样本个数，这一点常被误解。切到第 2 棵树看看，h 已经不再相等了。

成本：每个特征只需要在训练开始时排一次序（第 8 章的列块），之后每个节点、每个特征扫一遍，是线性时间。

第 6 章

长成一棵树：递归、停止与剪枝

找到根节点的最佳分裂后，对左右两个孩子重复同样的过程，树就一层层长出来。一个节点在下面几种情况下停下来当叶子：

  • 深度已经到了 max_depth；
  • 没有任何切分能让两侧的 H 都达到 min_child_weight；
  • 最好的切分也不能让目标函数下降（Gain ≤ 0）。

叶子确定后，每片叶子取 w* = −G/(H+λ)。左边的散点图是同一件事的另一面：每切一刀，就在特征空间里画一条线。

γ 的剪枝。exact 方法先把树长到 max_depth，再从下往上检查：一个节点的两个孩子都是叶子、而它的 Gain（已经减去 γ）小于 0，就把这次分裂剪掉。因为是自底向上，一个自身 Gain 不大、下面却接着一个大 Gain 的分裂会被保留。默认的 hist 方法则在展开节点时直接检查这个门槛。

对照源码

XGBoost 输出的 gain（get_dump(with_stats=True) 或 trees_to_dataframe() 里的 Gain）是方括号里那部分，既没有乘 ½，也没有减 γ。源码的剪枝条件是 gain < gamma，所以本页公式里的 γ 相当于参数 gamma 的一半。

另外，dump 出来的叶子值已经乘过 η，cover 就是 H。比如图 6 的根节点，xgboost 打印的是 gain=4.875, cover=4.25，本页显示 Gain = 4.875 / 2 = 2.438。

第 7 章

训练循环：更新预测，再来一棵

一棵树建好，所有样本的预测都往前走一小步：

ŷi(t) = ŷi(t−1) + η · w*qt(xi)

预测变了，g 和 h 也跟着变，下一棵树就在新的 g、h 上重做第 4–6 章的事情。右边的表格里能看到：已经分对的瓜 |g| 越来越小，h 也在变小，对后面的树影响越来越弱；还没分对的瓜 |g| 仍然很大，后面的树会继续盯着它们。

什么时候停？要么事先定好树的数量（num_boost_round 或 n_estimators），要么用验证集做早停：验证集上的指标连续若干轮（early_stopping_rounds）没有变好就停下，保留最好的那一轮。

多分类（multi:softprob）也是同一个循环，只是每一轮要为每个类别各建一棵树：K 个类别就有 K 套 g、h，每轮长 K 棵树。

第 8 章

工程加速：直方图、缺失值与并行

前面讲的是数学。XGBoost 能在上亿行数据上跑得快，还靠几项工程设计。

8.1 直方图算法（tree_method="hist"）

精确贪心要在每个节点把每个特征的每个取值都试一遍，数据一大就慢。hist 方法先把每个连续特征按分位数切成有限个桶（max_bin，默认 256），之后每个节点只要：

  1. 对每个特征建一张梯度直方图：每个桶里 g 的和、h 的和；
  2. 在桶的边界上从左往右扫描，用同一个 Gain 公式。

候选切分点从“不同取值的个数”降到最多 255 个，累加也变成按桶进行。XGBoost 2.0 起默认的 tree_method 就是 hist。

最后一步是 hist 的一个省力技巧：父节点的直方图 = 左孩子 + 右孩子。所以只需要对样本少的那个孩子真正统计一遍，另一个直接用减法得到。

分位点怎么取也有讲究。论文里的 approx 方法每棵树都用 h 作为权重重新取分位点（加权分位数草图）。原因是目标函数可以改写成以 hi 为权重的平方损失：

 Σi [ gif(xi) + 12hif(xi)2 ] =  Σi 12hi ( f(xi) − (−gi/hi) )2 + 常数

也就是说每个样本在拟合目标 −g/h，分量是 h，所以桶应该按 h 的总量均分。默认的 hist 方法更省事：训练开始前只取一次分位点（按样本权重），之后所有节点、所有树都复用这些桶。

8.2 缺失值：为每个节点学一个默认方向

真实数据里常有缺失值，或者大量的 0（比如 one-hot 编码之后）。XGBoost 的做法是：扫描时只遍历有值的样本；缺失的样本先整体放到右边扫一遍，再整体放到左边扫一遍，哪边的 Gain 更大，就把哪边记为这个节点的默认方向。预测时遇到缺失值，直接走默认方向。

这样处理的计算量只和非缺失值的个数成正比，数据越稀疏越划算。在论文的实验里，这种稀疏感知算法比朴素实现快了 50 倍以上。

8.3 系统层面

列块（Column Block）

数据按列压缩存储（CSC），每一列在训练开始前按特征值排好序，之后所有节点、所有树都复用，不用重复排序。缺失值直接不存。

一棵树内部并行

树和树之间必须串行，后一棵依赖前一棵的结果。并行发生在一棵树内部：不同特征的扫描、直方图的构建分给多个线程同时做；GPU（device="cuda"）也是同样的思路。

缓存感知与外存计算

按排序后的顺序读取 g、h 是跳跃访问，XGBoost 给每个线程开缓冲区预取，减少缓存未命中。数据放不进内存时，分块压缩存到磁盘，用单独的线程提前读下一块。

第 9 章

预测：一个新瓜走过所有树

训练完以后，预测一个新样本只需要让它从每棵树的根走到某片叶子，把所有叶子值加起来，再加上起点：

ŷ = base_margin + KΣk=1 η·w(k)qk(x)p = σ(ŷ) = 11 + e−ŷ

base_score = 0.5 对应的 log-odds 是 0。二分类最后过一次 sigmoid，把 log-odds 变成概率。在左边的图里拖动那个“?”，换一个瓜试试。

用真正的 XGBoost 复现图 6

下面这段代码用同样的数据和参数训练，打印出的第一棵树和图 6 一致（gain 是本页 Gain 的 2 倍，leaf 是 η·w*，cover 是 H）。

import numpy as np, xgboost as xgb

# 西瓜数据集 3.0α：密度、含糖率、是否好瓜
X = np.array([[.697,.460],[.774,.376],[.634,.264],[.608,.318],[.556,.215],[.403,.237],
              [.481,.149],[.437,.211],[.666,.091],[.243,.267],[.245,.057],[.343,.099],
              [.639,.161],[.657,.198],[.360,.370],[.593,.042],[.719,.103]])
y = np.array([1]*8 + [0]*9)

params = {"objective": "binary:logistic", "eta": 0.3, "max_depth": 3,
          "lambda": 1, "gamma": 0, "min_child_weight": 0.5,
          "base_score": 0.5, "tree_method": "exact"}
bst = xgb.train(params, xgb.DMatrix(X, label=y, feature_names=["density", "sugar"]),
                num_boost_round=20)
print(bst.get_dump(with_stats=True)[0])

# 0:[sugar<0.20449999] yes=1,no=2,missing=1,gain=4.87545776,cover=4.25
#     1:leaf=-0.300000012,cover=2
#     2:[density<0.381500006] yes=3,no=4,missing=3,gain=3.19813514,cover=2.25
#         3:leaf=-0.200000018,cover=0.5
#         4:leaf=0.381818205,cover=1.75

一句话串起来

  1. 从 base_score 出发，按当前预测给每个样本算出 g 和 h。
  2. 用 Gain 公式贪心地长出一棵树：逐个特征排序扫描，选 Gain 最大的切分，直到触发停止条件，再用 γ 剪枝。
  3. 每片叶子填上 w* = −G/(H+λ)。
  4. 预测加上 η 倍的新树输出，回到第 1 步，直到树的数量够了或验证集不再变好。
